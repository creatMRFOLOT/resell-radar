# resell-radar

Помощник для перекупов: следит за объявлениями на Avito и собирает в таблицу Excel кандидатов, на которых можно заработать. Для каждого объявления он считает чистую прибыль после комиссии, сравнивает цену с рынком по той же модели и объёму памяти и оценивает риск, что вам продают «кота в мешке». **Бот не заменяет человека**: он сужает выдачу до нескольких вариантов, а фото, переписку с продавцом и решение «брать или нет» берёте на себя вы.

*English: a tool for Avito resellers that finds underpriced phones, consoles and other devices, estimates market price per model and storage, margin after fees and a risk score, and writes the best deals to an Excel table. Docs below are in Russian.*

## Что умеет

- **Рынок по группам «модель + память».** S22 на 128 ГБ и на 256 ГБ не смешиваются в одну медиану. Цены, слишком далёкие от медианы (меньше 0.5× или больше 1.8×), в расчёт не идут: это обычно запчасти, мошенники и опечатки.
- **Состояние под ваши навыки.** При настройке вы выбираете, что умеете чинить: экран, заднее стекло, аккумулятор, плату, залитые, заблокированные. Не выбрали ничего, значит, нужны только целые телефоны. Выбрали, например, экран, и вам придут телефоны с разбитым экраном, а стоимость ремонта автоматически вычтется из прибыли.
- **Оценка риска 0–100** с объяснением причин: цена подозрительно низкая, мало данных о рынке, пустое описание, был ремонт, следы использования.
- **Описание читается.** Для кандидатов бот открывает объявление и ищет в тексте дефекты («перезагружается», «трещина на экране», «не включается»), понимая отрицания («трещин нет», «в ремонте не был»). Процент батареи, если продавец его указал, попадает в уведомление.
- **Только частные лица (по умолчанию).** Частники торгуются, и среди них реже встречаются «перебитые» устройства из мастерской. Можно выбрать «все» или «только магазины».
- **Не только телефоны.** Готовые наборы: Samsung Galaxy S22–S25, Google Pixel 7–9, iPhone 11–15, Nintendo Switch, PlayStation, Xbox, Steam Deck, iPad, MacBook Air, AirPods. Любое другое устройство добавляется в мастере по названию и разделу.
- **Поиск по образцу.** Дайте ссылку на конкретное объявление (нужная модель), и бот найдёт похожие. Из заголовка образца он берёт модель, отбрасывает память, цвет и рекламные слова, а варианты, которых в образце нет (Pro, Max, Ultra, Plus, mini, Lite, OLED), в выдачу не пускает. Это эвристика: запрос бот пишет в консоль («по образцу … ищем …»), и его всегда можно поправить в `config.toml` (`query`, `match`, `exclude`).
- **Поиск по вашей ссылке Avito.** Выставьте на Avito любые фильтры (состояние, цена, доставка, город), скопируйте ссылку из адресной строки и добавьте устройство «по ссылке»: программа использует ваши фильтры как есть.
- **Таблица Excel.** Все находки пишутся в `data/results.xlsx`: лучшие по прибыли сверху, ссылка на объявление кликабельна, есть фильтры по столбцам. Файл обновляется сам при каждой находке (если он открыт в Excel, закройте его: обновится при следующей находке, а полный журнал лежит в `data/results.csv`).
- **Избранное на Avito (по желанию).** Бот может ещё и добавлять находки в избранное под вашим аккаунтом. Перед первым запуском выполните `login.bat` и один раз войдите в аккаунт в окне Chrome. За цикл бот ставит не больше 15 «сердечек».
- Команда `top` показывает лучшие варианты прямо в консоли, `export` пересобирает таблицу.

## Быстрый старт (Windows)

1. Установите [Python 3.11+](https://www.python.org/downloads/) (отметьте «Add Python to PATH») и Google Chrome.
2. Дважды кликните `setup.bat`: поставятся зависимости и запустится мастер настройки. Мастер попросит указать **свои лимиты**: максимальную цену закупки и минимальную прибыль. Значений по умолчанию у лимита закупки нет, без него бот не запустится.
3. Дважды кликните `run.bat`. Chrome работает скрыто, окна не будет. Если Avito попросит проверку, окно появится само: пройдите её, и оно скроется. Не хотите скрывать окно, ответьте «нет» на вопрос мастера или поставьте `headless = false` в `config.toml`.

### Linux / macOS

```bash
pip install -r requirements.txt
python -m resell_radar setup
python -m resell_radar run
```

### Команды

| Команда | Что делает |
|---|---|
| `python -m resell_radar setup` | мастер настройки, создаёт `config.toml` |
| `python -m resell_radar run` | работает постоянно |
| `python -m resell_radar once` | один цикл и выход |
| `python -m resell_radar top` | лучшие найденные варианты |
| `python -m resell_radar debug` | сохраняет страницу выдачи в `data/debug` и показывает, что из неё разобрано (для поиска причин) |
| `python -m resell_radar login` | открывает Avito в Chrome, чтобы войти в аккаунт (нужно для избранного) |
| `python -m resell_radar export` | пересобрать таблицу `data/results.xlsx` из журнала |

## Как считается

```
рынок            = цены объявлений группы «модель + вариант» за 14 дней (без выбросов и дефектных)
цена продажи     = нижняя четверть рынка (q1)   или медиана со скидкой, или ваша sell_price
чистая прибыль   = цена продажи × (1 − комиссия 11%) − цена покупки − стоимость ремонта
```

Все цены берутся только из объявлений на Avito, никаких зарубежных цен в расчёте нет. Но цены в объявлениях выше реальных цен сделок: покупатели торгуются. Поэтому по умолчанию цена продажи берётся не по медиане, а по нижней четверти рынка (`sell_basis = "q1"`). Если и это завышено, задайте свою цену для модели: `sell_price` в секции `[[items]]`. Стоимость ремонта по умолчанию 0: у программы нет надёжной базы цен, вводите свои значения в мастере.

Группы внутри модели задаёт параметр `variant`: `storage` (объём памяти, подходит телефонам, планшетам и ноутбукам), `none` (вся модель одной группой, например наушники и консоли) или регулярка, первая скобка которой даёт название варианта.

Бот добавляет объявление в таблицу, если прибыль не ниже `min_margin`, цена не выше `max_buy`, а риск не выше `risk_max`. Все числа настраиваются в `config.toml` (пример: `config.example.toml`). Для любой модели можно задать свою цену продажи (`sell_price`) и свой лимит закупки (`max_buy`).

## Ограничения (читайте)

- **Это эвристики, а не гарантия.** Бот не видит фото и не знает, что продавец не написал. Состояние и фото всегда проверяйте сами.
- **Вёрстка Avito меняется.** Все селекторы собраны в `resell_radar/parser.py`. Если бот перестал находить объявления, чинить нужно только этот файл.
- **Капчу бот не решает и защиту Avito не обходит.** Он открывает страницы в обычном Chrome с паузами. Скрытый режим Avito может замечать чаще обычного. Если Avito просит проверку, бот на время показывает окно, вы проходите её руками, и работа продолжается. Используйте умеренную частоту (по умолчанию раз в 15 минут): Avito может ограничить доступ по IP.
- **Правила сайта.** Автоматический сбор данных может нарушать пользовательское соглашение Avito. Используйте проект на свой риск и для личных целей.
- **Избранное не проверено на живом Avito.** Кнопка ищется по нескольким вариантам (`FAVORITE_SELECTORS` в `browser.py`). Если не нашлась или вход не выполнен, бот пишет предупреждение в консоль, а находка всё равно попадает в таблицу. Автоматические клики под аккаунтом могут не понравиться Avito: начните с небольшого числа моделей.
- **Фильтр продавцов.** Программа добавляет к ссылке параметр `user=1` (частные лица) или `user=2` (компании). Я не мог проверить его на живом Avito. Если фильтр не срабатывает, выберите «Частные» на сайте, скопируйте получившуюся ссылку и добавьте устройство «по ссылке»: параметры из неё программа не меняет.

## Структура

```
resell_radar/
  config.py      настройки, чтение и запись config.toml
  presets.py     готовые модели (регулярки по заголовку)
  wizard.py      мастер первой настройки
  urls.py        сборка поисковых ссылок, фильтр продавца, проверка ссылок
  examples.py    поиск по образцу: запрос и фильтры из заголовка объявления
  parser.py      разбор HTML Avito (единственное место с селекторами)
  browser.py     Chrome через Playwright, постоянный профиль
  condition.py   дефекты по тексту и решение «подходит ли вам»
  market.py      объём памяти, группы, медиана без выбросов
  scoring.py     прибыль, окупаемость, риск
  engine.py      один цикл мониторинга
  storage.py     что уже видели, журнал CSV и таблица Excel
tests/           97 тестов (python -m unittest discover -s tests -t .)
```

## Разработка

```bash
python -m unittest discover -s tests -t .
```

Тесты используют поддельные страницы Avito (`tests/helpers.py`) и не ходят в сеть. Чтобы добавить новую модель, добавьте регулярки в `presets.py` или секцию `[[items]]` в `config.toml` и проверьте их тестом на реальных заголовках.
